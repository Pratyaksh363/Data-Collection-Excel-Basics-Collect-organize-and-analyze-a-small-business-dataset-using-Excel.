# 📊 Vrinda Store Data Analysis

## 📌 Project Overview

**Vrinda Store Data Analysis** is an Excel-based data analysis project focused on collecting, organizing, cleaning, and analyzing retail sales data.

The project demonstrates how Microsoft Excel can be used to transform raw sales records into meaningful business insights through data cleaning, calculations, summaries, and visualizations.

The analysis helps understand **sales performance, customer purchasing patterns, product categories, order trends, and overall business performance**.

---

## 🎯 Objectives

* Collect and organize retail sales data.
* Clean and prepare the dataset for analysis.
* Perform basic data analysis using Excel.
* Calculate important sales and business metrics.
* Identify sales and customer trends.
* Analyze product and category performance.
* Create charts and visualizations.
* Present findings in an easy-to-understand dashboard/report.

---

## 🗂️ Dataset

The dataset contains retail order information such as:

| Column     | Description                                   |
| ---------- | --------------------------------------------- |
| Order ID   | Unique identification number for each order   |
| Order Date | Date on which the order was placed            |
| Customer   | Name/identifier of the customer               |
| Gender     | Customer gender                               |
| Age        | Customer age                                  |
| State      | Customer's state/location                     |
| Channel    | Platform through which the order was received |
| Product    | Product purchased                             |
| Category   | Product category                              |
| Quantity   | Number of items purchased                     |
| Sales      | Revenue generated from the order              |

## 🔄 Analysis Process

### 1. Data Collection

Collected and organized the store's sales records into a structured Excel dataset.

### 2. Data Cleaning

Checked the dataset for inconsistencies, missing values, incorrect formats, and duplicate records before analysis.

### 3. Data Organization

Converted the raw data into a structured table with clearly defined columns and consistent formatting.

### 4. Data Analysis

Used Excel formulas, Pivot Tables, and summaries to analyze:

* Total sales
* Order volume
* Customer demographics
* Product performance
* Category performance
* State-wise sales
* Sales channels
* Monthly/periodic sales trends

## 💡 Business Insights
Women are more likely to buy compared to men (~65%)
Maharashtra, Karnataka, Uttar Pradesh are the top 3 states (~35%)
Adult age group is the most contributing (~50%)
Amazon, Flipkart and myntra are the most contributing (~80%)
